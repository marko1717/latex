# Джерела завдань НМТ-2026 (копії для відтворюваної збірки)

* `збірник/оригінали/Оригінали_Розділ_1..6.tex` — оригінали сесій 23.05–5.06 по розділах (152 завдання; без 2.06 №14 і 3.06 №5).
* `збірник/розділи/Розділ_1..6.tex` — ті самі блоки з аналогами та розв'язками (розділ «РОЗВ'ЯЗКИ ОРИГІНАЛЬНИХ ЗАДАЧ»).
* `збірник/збірник_НМТ_тиждень.tex` — збірник тижня 1 (звідси береться 3.06 №5).
* `збірник/nmt_2026_bank.json` — банк із відповідями/розв'язками (перевірка).
* `сесії/<дата>/завдання.tex` — повні сирі варіанти сесій 8.06–19.06 (по 22 завдання), `завдання_key.tex` — з відповідями.
