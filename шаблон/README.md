# Шаблон формату НМТ-2026

* `преамбула_2026.tex` --- преамбула, однакова в усіх файлах бази. Її генерує
  `scripts/build_nmt_2023_2026.py` (константа `PREAMBLE`), тож правити її треба
  в скрипті, а не в окремих файлах: інакше зміну затре наступна збірка.
* `приклад_документа.tex` --- той самий преамбул плюс кілька завдань; компілюється
  XeLaTeX і слугує заготовкою для нового документа.

Шрифти `Schoolbook-*.otf` лежать у корені репозиторію; шлях у преамбулі
підбирається автоматично (`../`, `./`, `../../`), а якщо файлів немає ---
підставляється TeX Gyre Schola, і документ усе одно збереться.
