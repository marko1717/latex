# Звірка з тематичним збірником «Числа і вирази, 234 завдання НМТ 2022–2025»

Другий контрольний збірник того самого автора, зібраний по підтемах
(числові множини, степінь, одночлени, многочлени, ФСМ, розкладання на множники,
раціональні вирази, модуль, ірраціональні вирази, тригонометричні,
показникові, логарифмічні вирази). Кожне завдання підписано роком і типом
сесії: **основна**, **додаткова** або **демоваріант**.

## Склад збірника

| Рік і сесія | Завдань |
|-------------|---------|
| 2023, основна | 78 |
| 2023, додаткова | 7 |
| 2024, основна | 70 |
| 2025, основна | 69 |
| 2025, додаткова | 7 |
| 2022, демоваріант | 3 |
| **Разом** | **234** |

## Особливості розбору

Номери завдань набрано в кружечках, і в текстовому шарі вони змішані з гліфом
кружечка, а формули розпізнано з помилками (документ проходив OCR). Тому номери
відновлено як зростаючу послідовність 1…234 серед чисел у лівому полі
(`extract2.py`), а зіставлення з базою (`match2.py`) спирається насамперед на
набір варіантів відповіді й «плаский» вигляд формул, а не на текст умови.

```bash
python3 scripts/звірка_тематичний_збірник/extract2.py   # PDF -> tasks2.json
python3 scripts/звірка_тематичний_збірник/match2.py     # зіставлення з базою
```
