# Рисунки до завдань через OpenAI API

Інструкція до `scripts/рисунок_api.py`. Це один файл, який працює в будь-якій гілці чи репозиторії: база НМТ, маніфест і збирач йому не потрібні. Факти про API актуальні на вересень 2026.

**Головне правило.** Генератор малює лише «картинку»: предмет, пейзаж, фото. Усе, від чого залежить відповідь, малює TikZ поверх картинки: кількості, підписи кирилицею, точки, кути, відрізки. Генератор не гарантує ні точної кількості предметів, ні правильної кирилиці. Композицію придумуємо самі за текстом завдання, а не копіюємо оригінальний рисунок чи фото з НМТ.

## Коротко

```bash
python3 scripts/рисунок_api.py перевірити
python3 scripts/рисунок_api.py згенерувати "A plastic bottle of kefir with a large blank white label, straight front view" "2.відсотки, арифметичні задачі, подільність/nmt_kefir_bottle.png" --прозорий --формат 1024x1536 --ширина 500
```

Далі:
1. Відкрити готовий PNG і подивитися, чи підходить.
2. Вставити його в LaTeX через `\includegraphics` усередині `tikzpicture` і накласти підписи TikZ (розділ 5).
3. Скомпілювати й переглянути сторінку.

## 1. Один раз: доступ до API

1. **Ключ.** На platform.openai.com: API keys → Create new secret key.
2. **Оплата.** Поповнити Billing щонайменше на 5 $ (це Tier 1: до 5 зображень на хвилину). Безкоштовного рівня для зображень немає.
3. **Верифікація організації.** Settings → Organization → General → Verify Organization. Потрібен документ, один документ підходить лише для однієї організації. Без верифікації генерація повертає 403. Після верифікації доступ вмикається не одразу: від 15 хвилин до доби.
4. **Ліміт витрат (рекомендую).** Settings → Limits → Spend (для всієї організації) або Project → Limits (для одного проєкту), з увімкненим жорстким лімітом. Коли ліміт вичерпано, запити отримують 429 і гроші більше не списуються.
5. **Ключ у змінну середовища.** Лише так: додати в `~/.zshrc` рядок

   ```bash
   export OPENAI_API_KEY="sk-proj-..."
   ```

   і відкрити новий термінал або виконати `source ~/.zshrc`. Ключ не вставляйте в чат, у файли й у коміти. Скрипт бере його лише зі змінної й ніде не друкує. Якщо ключ засвітився, відкличте його на тій самій сторінці API keys і створіть новий.
6. **Pillow** (для обробки картинок): `pip3 install pillow`.
7. **Перевірка:** `python3 scripts/рисунок_api.py перевірити`. Цей запит безкоштовний: він показує, чи робочий ключ і які моделі доступні. Верифікацію він не перевіряє, 403 проявиться лише під час генерації.

**У Claude Code** (desktop-застосунок) оболонка може не читати `~/.zshrc`. Тоді запускайте так:

```bash
zsh -ic 'cd ~/Desktop/*/НМТ_по_темах_латех && python3 scripts/рисунок_api.py перевірити'
```

## 2. Як перенести в іншу гілку чи репозиторій

- **Та сама репа, інша гілка:**

  ```bash
  git checkout назва-гілки
  git checkout main -- scripts/рисунок_api.py scripts/РИСУНКИ_ЧЕРЕЗ_API.md
  ```

  Друга команда бере ці два файли з `main` і кладе в поточну гілку. Далі їх треба закомітити.
- **Інший репозиторій** (наприклад `dz` чи `matematyka-11-klas`): скопіювати один файл `рисунок_api.py`. Інших залежностей, крім Pillow, немає.
- **У `.gitignore` тієї гілки** додати рядок `*_raw.png`, щоб сирі зображення не потрапляли в коміти.

## 3. Генерація

```bash
python3 scripts/рисунок_api.py згенерувати "ОПИС" тека/nmt_назва.png [параметри]
```

| Параметр | Що робить |
|---|---|
| `--прозорий` | прозорий фон (PNG); потрібен для предметів, поверх яких TikZ щось малює |
| `--формат` | `1024x1024` (типово), `1024x1536` (вертикальний), `1536x1024` (горизонтальний), `auto` |
| `--якість` | `low` (чернетка, найдешевше), `medium` (типово), `high`, `auto`; для моделей `gpt-image-2.5` ще `xhigh` і `max` |
| `--скільки N` | N варіантів за один запит (1–10) → `nmt_назва_1.png`, `nmt_назва_2.png`, … |
| `--ширина` | ширина готового PNG у пікселях (типово 1000; для дрібних предметів 500–800) |
| `--без-стилю` | не додавати стильову приставку (для «фото»: стиль описати в самому описі) |
| `--без-обробки` | лишити тільки сире зображення |
| `--модель` | модель явно; інакше береться змінна `OPENAI_IMAGE_MODEL` або автоматичний вибір |
| `--лише-запит` | нічого не надсилати, лише показати тіло запиту (безкоштовно) |

Для `тека/nmt_назва.png` скрипт записує три файли:

| Файл | Що в ньому |
|---|---|
| `тека/nmt_назва_raw.png` | сире зображення від API; у LaTeX не вставляти, у git не комітити |
| `тека/nmt_назва.png` | готове: обрізані порожні поля, зменшене, стиснуте. Його й вставляємо |
| `тека/nmt_назва.json` | опис, модель, формат, дата, орієнтовна ціна; щоб потім повторити |

**Імена файлів латиницею** (`nmt_kefir_bottle.png`, а не `кефір.png`): LaTeX і Overleaf з кирилицею в іменах працюють ненадійно.

**Обробити вже наявну картинку** (наприклад, вибрати іншу з кількох варіантів чи змінити ширину):

```bash
python3 scripts/рисунок_api.py обробити тека/nmt_назва_2_raw.png тека/nmt_назва.png --ширина 700 --прозорий
```

### Як писати опис

- Англійською, конкретно: що за предмет, який ракурс, які деталі.
- Скрипт сам додає стильову приставку: плаский векторний стиль, м'які кольори, без тексту, літер, чисел, підписів і водяних знаків. Для прозорого фону приставка інша: ізольований предмет на прозорому тлі.
- **Для прозорого фону не описуйте тло чи сцену.** Опис важить більше за параметр: якщо в описі є «на столі», «у кімнаті», «білий фон», модель може намалювати фон замість прозорості. Скрипт попередить, якщо фон вийшов непрозорим.
- Не просіть кількостей, підписів чи чисел. Якщо на предметі мають бути написи (етикетка, табличка), просіть порожню етикетку (`a large completely blank white label`), а текст накладе TikZ.
- Для «фото» додайте `--без-стилю` і опишіть стиль самі: `Studio product photo ..., pure white background, grayscale, no text, no logos.`

Промпти, які спрацювали з першої спроби:

- Озеро (`--прозорий --формат 1536x1024`):
  > A single small lake seen from above at a slight angle: an irregular rounded patch of light blue water with a few soft white ripple strokes, a thin sandy shore, three or four small round green trees and a few grass tufts around the edge, isolated object on a transparent background.
- Кефір (`--прозорий --формат 1024x1536`):
  > A plastic bottle of kefir (a cultured milk drink): white bottle with a blue screw cap and a large completely blank white rectangular label on the front, no text, no logos, no letters, straight front view, isolated object on a transparent background.

**Економія.** Спершу `--якість low --скільки 3`: три чернетки коштують близько 0,02 $. Якщо ідея подобається, згенеруйте фінальний варіант з `medium`. Але це буде нове зображення, не «покращена» чернетка.

## 4. Перевірити результат

- Відкрийте готовий PNG. Перевірте, що на ньому немає тексту чи зайвих деталей, фон прозорий (якщо просили) і предмет цілий.
- Не підходить: змініть опис і згенеруйте ще раз. Опис і модель попередньої спроби лежать у `.json` поряд.
- Після вставлення в LaTeX обов'язково скомпілюйте й подивіться на сторінку. Лише так видно, чи підписи TikZ стоять на своїх місцях.

## 5. Вставлення в LaTeX

**Шлях до картинок.** Якщо PNG лежить у теці теми, а документ компілюється з кореня проєкту (як в Overleaf), вкажіть теку:

```latex
\graphicspath{{./}{36. Теорія ймовірності/}}
```

Назва теки в `\graphicspath` має **побайтно** збігатися з назвою в репозиторії. На Mac назви тек бувають у «розкладеній» формі Unicode (NFD: «й» = «и» + знак бреве), а в git і на Overleaf вони в складеній (NFC). Локально все компілюється, а Overleaf пише «File not found». Якщо набираєте шлях руками, усе гаразд. Якщо його пише скрипт, нормалізуйте: `unicodedata.normalize("NFC", шлях)`.

**Шаблон 1: підписи поверх картинки** (кефір). Координати від 0 до 1 рахуються відносно самої картинки: (0,0) — лівий нижній кут, (1,1) — правий верхній. Тому підписи не зсуваються, навіть якщо змінити розмір.

```latex
\begin{center}
\begin{tikzpicture}
    % пляшка -- згенероване зображення; текст етикетки -- TikZ
    \node[inner sep=0, anchor=south west] (b) at (0,0) {\includegraphics[height=6.2cm]{nmt_kefir_bottle.png}};
    \begin{scope}[x={(b.south east)}, y={(b.north west)}]
        \node[font=\small\bfseries] at (0.5,0.535) {Кефір};
        \node[font=\scriptsize] at (0.5,0.41) {жиру 2\,\%};
        \node[font=\scriptsize] at (0.5,0.325) {Маса 900 г};
    \end{scope}
\end{tikzpicture}
\end{center}
```

Положення підписів підбирають за готовою картинкою: скомпілювати, подивитися, підправити числа.

**Шаблон 2: картинки-«спрайти» і точні лінії** (база відпочинку й три озера). Скорочено:

```latex
\begin{tikzpicture}[x=1cm, y=1cm]
    \tikzset{stezhka/.style={line width=1.5pt, brown!70!black, line cap=round}}
    % стежки -- TikZ, щоб кількість (2, 4, 3) була точною; малюються ДО картинок,
    % тоді прозорі картинки акуратно накривають кінці ліній
    \draw[stezhka] (-0.75,2.05) to[out=205,in=15] (-3.0,0.95);
    \draw[stezhka] (-0.6,1.95) to[out=225,in=5] (-2.9,0.15);
    % ... решта стежок
    \node[inner sep=0] at (-4.3,0.4) {\includegraphics[width=3.8cm]{nmt_lake.png}};
    \node[inner sep=0] at (4.3,0.4) {\reflectbox{\includegraphics[width=3.8cm]{nmt_lake.png}}};
    \node[inner sep=0] at (0,3.05) {\includegraphics[width=2.6cm]{nmt_zatyshna_house.png}};
    \node[font=\small\bfseries] at (0,4.55) {База відпочинку «Затишна»};
    \node[font=\small] at (-4.3,1.95) {Озеро Прозоре};
\end{tikzpicture}
```

Одну картинку можна використати кілька разів: з різною шириною або віддзеркалену через `\reflectbox`.

**Шаблон 3: фото поруч зі схемою** (підставка для планшета): TikZ-схема як «Рис. 1», фото як «Рис. 2».

```latex
\begin{center}
\begin{tabular}{c@{\hspace{1.5cm}}c}
\begin{tikzpicture}[scale=1.15, thick]
    % ... схема з точками й кутами
\end{tikzpicture}
&
\raisebox{0.1cm}{\includegraphics[height=3.2cm]{nmt_tablet_stand.png}}
\\[0.1cm]
\small Рис. 1 & \small Рис. 2
\end{tabular}
\end{center}
```

## 6. Моделі, ціни, ліміти (вересень 2026)

- **Модель.** Скрипт сам вибирає `gpt-image-2-2026-04-21`: на ній зроблено рисунки бази, і вона працює з прозорим фоном. Далі йдуть `gpt-image-2`, `gpt-image-2.5-flare` і `gpt-image-2.5-sunburst`. Моделі з оголошеною датою вимкнення скрипт бере лише тоді, коли інших немає.
- **Новіші моделі** `gpt-image-2.5-flare` (швидка) і `gpt-image-2.5-sunburst` (найточніша) мають якості `xhigh` і `max` і повноцінну підтримку прозорого фону. Перемкнутися можна через `--модель gpt-image-2.5-sunburst`. У `gpt-image-2` прозорий фон має статус preview (з 20.08.2026), але в нас він працював.
- **Що вимикається.** `gpt-image-1` вимкнуть 23.10.2026, `gpt-image-1.5` і `gpt-image-1-mini` — 01.12.2026. DALL·E уже вимкнено.
- **Ціна `gpt-image-2` за одне зображення** (без вхідного тексту, це копійки):

  | Якість | 1024×1024 | 1024×1536 / 1536×1024 |
  |---|---|---|
  | low | 0,006 $ | 0,005 $ |
  | medium | 0,053 $ | 0,041 $ |
  | high | 0,211 $ | 0,165 $ |

- **Ціна моделей 2.5** рахується за токенами. Скрипт після кожного запиту друкує орієнтовну ціну і записує її в `.json`.
- **Ліміти.** Tier 1 (після поповнення на 5 $): 5 зображень на хвилину. Більше ліміти стають після більших сум оплат.

## 7. Помилки

| Код | Що означає | Що робити |
|---|---|---|
| 401 | ключ не прийнято | перевірити змінну: без пробілів і зайвих символів, ключ не відкликано, він з того самого проєкту |
| 403 «must be verified» | організацію не верифіковано або доступ ще не ввімкнувся | пройти верифікацію й почекати; скрипт сам повторює двічі |
| 403 інше | країна чи регіон, доступ до проєкту | читати текст помилки |
| 429 `insufficient_quota`, `…spend_limit_exceeded` | закінчилися кошти або ліміт витрат | поповнити Billing чи підняти ліміт; скрипт не повторює |
| 429 `rate_limit_exceeded` | забагато запитів за хвилину | скрипт чекає й повторює сам |
| 400 `moderation_blocked` | опис відхилив фільтр безпеки | переформулювати опис |
| 400 інше | неприпустимий параметр (розмір, якість, модель) | див. текст помилки й розділ 6 |
| 500, 502, 503 | збій на боці OpenAI | скрипт повторює сам |

Складна картинка може генеруватися до 2 хвилин, це нормально.

## 8. Текст для Claude в іншій гілці чи чаті

Скопіюйте й вставте на початку роботи:

> У репозиторії є `scripts/рисунок_api.py` та інструкція `scripts/РИСУНКИ_ЧЕРЕЗ_API.md`, прочитай її. Ключ OpenAI лежить лише в змінній `OPENAI_API_KEY` у `~/.zshrc`. Запускай скрипт через `zsh -ic '...'`, ключ ніколи не друкуй і не записуй у файли. Спершу виконай `перевірити`. Генератор малює лише картинку без тексту й чисел. Усе точне (кількості, підписи кирилицею, точки, кути) малюй у TikZ поверх `\includegraphics`. Композицію придумуй сам за текстом завдання, не копіюй оригінальний рисунок. PNG називай латиницею (`nmt_...`) і клади в теку теми, `*_raw.png` не комить. Після вставлення скомпілюй, відрендер сторінку в PNG і переглянь. Генеруй лише ті рисунки, які я прошу, спершу з `--якість low`.

## 9. А `scripts/рисунки.py`?

Це версія для бази НМТ у `main`:
- опис кожного рисунка лежить у маніфесті `scripts/data/рисунки.json`;
- вставки в завдання — у `scripts/data/вставки_рисунків.json`, їх застосовує збирач `build_nmt_2023_2026.py`.

Для всього іншого (інша гілка, інший репозиторій, разовий рисунок) простіше взяти `рисунок_api.py`.
