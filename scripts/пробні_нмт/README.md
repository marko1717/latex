# База й пробні НМТ з математики

Пробний НМТ -- 22 **нові авторські** завдання за структурою НМТ 2026 (15 тестових, 3 на відповідність, 4 з короткою
відповіддю, 32 бали). Кожне завдання -- певного **типу** з каталогів типів (`scripts/типи_*`), а які типи брати й
як часто -- показує **база** всіх завдань НМТ 2023--2026, класифікованих за цими типами.

## База: `scripts/data/пробні_база.json`

```bash
python3 scripts/пробні_нмт/база.py        # зібрати базу й надрукувати частоти типів 2026 року по слотах
```

* **Оригінали** НМТ 2023--2026 (1597, з каталогу генератора варіантів `scripts/data/варіант_каталог.json`: перевірені
  відповіді, рік, сесія, дефекти). Тип кожного -- `scripts/data/типи_класифікація.json`: два незалежні класифікатори на
  слот і арбітр для розбіжностей (розійшлися в 3 %), без типу -- 18 завдань, яких жоден тип не описує.
* **Аналоги** з бібліотеки генератора (`варіант_згенеровані.json`) -- тип успадковано від завдання-зразка.
* **Зразки каталогів** типів -- по одному новому завданню на тип.
* **Авторські завдання пробних** -- `пробні/<пробний>/завдання.json`; у полі `використано` -- у якому пробному
  (чи варіанті) завдання вже було, щоб не повторювати.

Для кожного типу база знає частоти за роками **в кожному слоті окремо** (типи рівнянь спільні для слотів «рівняння» і
«рівняння_трансц») і теми бази (1--43), до яких належать його оригінали.

Ключ типу -- `каталог:код`, наприклад `алгебра:Д9`, `кв_стерео:КС14` (коди В1..В9 є і в рівняннях, і в геометрії).

## Підбір типів

```bash
python3 scripts/пробні_нмт/підбір.py --заборонені-теми 34 40 41 42 --заборонені-типи алгебра:Ї8 --seed 1
```

Для кожного слота -- тип із вагою за частотою (2026 : 2025 : 2024 : 2023 = 4 : 1,5 : 0,8 : 0,4), лише з тем, які
учні вже пройшли, і так, щоб **родина тем** (прогресія, логарифми, призма, піраміда ...) не повторювалася, крім функцій.
Це підказка: остаточний план складається вручну (наприклад, у слоті 20 у 2026 році щоразу були відсотки).

## Пробний

```bash
python3 scripts/пробні_нмт/пробний.py пробні/клас_1
```

`пробні/<пробний>/спец.py` -- `КОНФІГ` (назва, для кого, заборонені теми й типи, обов'язкові умови) і `ЗАВДАННЯ` у
порядку слотів. Кожне завдання описано так само, як зразки каталогів: умова, варіанти (або пункти відповідності, або
обчислення короткої відповіді), **правильна відповідь обчислюється** (sympy), дистрактори -- названі типові помилки
(для короткої відповіді кожну пастку обчислено хибним способом), рисунок -- TikZ (`scripts/типи_спільне/рисунки*.py`).

Скрипт перевіряє завдання засобами `scripts/типи_спільне/збирач.py` (рівно один правильний варіант, конкурентні
дистрактори, вирівняні літери, різні ключі 16--18, відповідь для бланка) і склад (слоти, типи, родини тем, заборонені
теми), пише `завдання.json`, `склад.json` і в теку `пробні/`:

* `<Файл>.tex` / `.pdf` -- пробний з водяним знаком @pvtr2525;
* `<Файл>_без_водяного_знака.tex` / `.pdf` -- для вчителів;
* `<Файл>_відповіді.tex` / `.pdf` -- ключ, розв'язки, тип і типові помилки кожного завдання.

Після збирання -- наскрізна перевірка (воркфлоу): сторінки рендеряться в PNG, два незалежні «учні» розв'язують усі 22
завдання з картинок, критик звіряє рівень і пастки з реальними завданнями НМТ того самого типу й перевіряє теми,
рецензент дивиться рисунки й верстку.

| Тека | Для кого | Теми |
|---|---|---|
| `пробні/клас_1` | клас, кінець жовтня 2026 | 5--10 клас і пройдене в 11-му: показникові, логарифми, призма, паралелепіпед, піраміда; без первісної, тіл обертання й формул комбінаторики |
| `пробні/канал_1` | канал @pvtr2525, повний пробний | усі теми, частоти типів -- як на НМТ 2026 |
