# База й пробні НМТ з математики

Пробний НМТ -- 22 **нові авторські** завдання за структурою НМТ 2026 (15 тестових, 3 на відповідність, 4 з короткою
відповіддю, 32 бали). Кожне завдання -- певного **типу** з каталогів типів (`scripts/типи_*`), а які типи брати й
як часто -- показує **база** всіх завдань НМТ 2023--2026, класифікованих за цими типами.

## База: `scripts/data/пробні_база.json`

```bash
python3 scripts/пробні_нмт/база.py        # зібрати базу й надрукувати частоти типів 2026 року по слотах
```

* **Оригінали** НМТ 2023--2026 (1597, з каталогу генератора варіантів `scripts/data/варіант_каталог.json`: перевірені
  відповіді, рік, сесія, дефекти). Тип кожного -- `scripts/data/типи_класифікація.json`: два незалежні класифікатори на
  слот і арбітр для розбіжностей (розійшлися в 3 %), без типу -- 18 завдань, яких жоден тип не описує.
* **Аналоги** з бібліотеки генератора (`варіант_згенеровані.json`) -- тип успадковано від завдання-зразка.
* **Зразки каталогів** типів -- по одному новому завданню на тип.
* **Авторські завдання пробних** -- `пробні/<пробний>/завдання.json`; у полі `використано` -- у якому пробному
  (чи варіанті) завдання вже було, щоб не повторювати.

Для кожного типу база знає частоти за роками **в кожному слоті окремо** (типи рівнянь спільні для слотів «рівняння» і
«рівняння_трансц») і теми бази (1--43), до яких належать його оригінали.

Ключ типу -- `каталог:код`, наприклад `алгебра:Д9`, `кв_стерео:КС14` (коди В1..В9 є і в рівняннях, і в геометрії).

## Підбір типів

```bash
python3 scripts/пробні_нмт/підбір.py --заборонені-теми 34 40 41 42 --заборонені-типи алгебра:Ї8 --seed 1
```

Для кожного слота -- тип із вагою за частотою (2026 : 2025 : 2024 : 2023 = 4 : 1,5 : 0,8 : 0,4), лише з тем, які
учні вже пройшли, і так, щоб **родина тем** (прогресія, логарифми, призма, піраміда ...) не повторювалася, крім функцій.
Це підказка: остаточний план складається вручну (наприклад, у слоті 20 у 2026 році щоразу були відсотки).

## Пробний

```bash
python3 scripts/пробні_нмт/пробний.py пробні/клас_1
```

`пробні/<пробний>/спец.py` -- `КОНФІГ` (назва, для кого, заборонені теми й типи, обов'язкові умови) і `ЗАВДАННЯ` у
порядку слотів. Кожне завдання описано так само, як зразки каталогів: умова, варіанти (або пункти відповідності, або
обчислення короткої відповіді), **правильна відповідь обчислюється** (sympy), дистрактори -- названі типові помилки
(для короткої відповіді кожну пастку обчислено хибним способом), рисунок -- TikZ (`scripts/типи_спільне/рисунки*.py`).

Скрипт перевіряє завдання засобами `scripts/типи_спільне/збирач.py` (рівно один правильний варіант, конкурентні
дистрактори, вирівняні літери, різні ключі 16--18, відповідь для бланка) і склад (слоти, типи, родини тем, заборонені
теми), пише `завдання.json`, `склад.json` і в теку `пробні/`:

* `<Файл>.tex` / `.pdf` -- пробний з водяним знаком @pvtr2525;
* `<Файл>_без_водяного_знака.tex` / `.pdf` -- для вчителів;
* `<Файл>_відповіді.tex` / `.pdf` -- ключ, розв'язки, тип і типові помилки кожного завдання.

Після збирання -- наскрізна перевірка (воркфлоу): сторінки рендеряться в PNG, два незалежні «учні» розв'язують усі 22
завдання з картинок, критик звіряє рівень і пастки з реальними завданнями НМТ того самого типу й перевіряє теми,
рецензент дивиться рисунки й верстку.

## Кандидат на одне завдання

```bash
python3 scripts/пробні_нмт/кандидат.py кандидат.py --mock клас_1 --out /tmp/png
```

`кандидат.py` -- фрагмент у форматі `спец.py` (допоміжні змінні + один виклик `з(...)`), виконується в просторі імен
спец.py пробного й **заміняє** завдання свого слота. Друкує перевірки збирача (один правильний варіант, пастки, якість
дистракторів, відповідь для бланка), перевірку складу (родини тем, заборонені теми й типи) і рендерить сторінку з
завданням у PNG. Так переробляли пробні за рецензією вчителя: на слот -- кілька кандидатів від різних авторів, суддя
розв'язує їх наосліп і вибирає, потім кандидат вписується в `спец.py`.

## Експорт для платформи (LearningPlatform)

```bash
python3 scripts/пробні_нмт/експорт_платформа.py пробні/канал_1        # -> ~/Downloads/Пробні_НМТ/<Файл>_для_платформи/
```

`.tex` у форматі парсера платформи (`nmt-platform/scripts/parse_variant.py`: 22 завдання за `\zadtask`/`\zadnum`,
пункти відповідностей як `\textbf{1..3}`/`\textbf{А..Д}`, ключ у кінці після `\sectionTitle{ВІДПОВІДІ}`), `.json` з
відповідями, розв'язками й типовими помилками, фото до завдань і PDF. Перевірка: `parse_variant.py` має показати
«завдань: 22 | ключ: 22».

## PDF для каналу в оформленні авторських варіантів

```bash
python3 scripts/пробні_нмт/оформлення_канал.py пробні/канал_1 ОБКЛАДИНКА.png "~/Downloads/4 червня автор 2.pdf" ВИХІД.pdf
```

Обкладинка (згенерована через `scripts/рисунок_api.py`, 1024x1536, вписується в A4) -> сторінки «Про мене» й довідкові
матеріали з готового PDF (за замовчуванням сторінки 2--5 авторського варіанта за 4 червня) -> «АВТОРСЬКИЙ ВАРІАНТ НМТ»
(колонтитул «Авторський варіант НМТ», інструкції без бланка відповідей, водяний знак) -> сторінка «ВІДПОВІДІ».
Сторінка «Про мене» без ШІ-картинок -- `python3 scripts/пробні_нмт/про_мене.py ФОТО.png про_мене.pdf` (зін-стиль дизайн-системи
~/nmt-slides: тло-папір, картки з чорнильною рамкою й жорсткою тінню, штампи, маркер, Mulish; справжнє фото й QR-код на канал);
у збирання -- параметр `--про-мене про_мене.pdf` (тоді з PDF беруться лише довідкові сторінки 3--5).
Обкладинка в тому ж зін-стилі -- `python3 scripts/пробні_нмт/обкладинка_зін.py обкладинка.pdf --постер ПОСТЕР.png` (цілком
згенерований постер 1024x1536 з написами -- картка з рамкою й тінню на папері) або `--ілюстрація ІЛЮСТРАЦІЯ.png` (згенерована
ілюстрація без написів + зверстані штамп, заголовок, чипи й канал; тло сторінки -- колір країв ілюстрації); готовий PDF
передається збирачу замість PNG обкладинки. Написи на згенерованому постері перевіряти очима (помилки, переплутані позначення).
Сам варіант у тому ж стилі -- параметр `--дизайн зін` (`scripts/пробні_нмт/тема_зін.py`): перевизначає макроси бази
(`\zadtask`, `\answerTable`, `\matchingLayout`, `\matchItem`, `\matchingGrid`, `\nmtAnswerBox`, `\instructionBox`), тож завдання не
змінюються: кожне завдання -- картка з номером-пігулкою, варіанти А--Д -- картки з літерою-міткою, відповідність -- темні мітки 1--3 й
світлі А--Д, сітка й поле відповіді із заокруглених клітинок, інструкції -- картки «ЧАСТИНА N», на решті останньої сторінки --
«ЧЕРНЕТКА» в клітинку, відповіді -- шавлієві картки й поле «Мій результат». Текст -- Mulish, формули -- Schoolbook
(`--текст schoolbook` -- текст теж шрифтом бази). Картки не розриваються, тож варіант довший (канал_1: 7 сторінок замість 5).
Довідкові матеріали в тому ж стилі -- `python3 scripts/пробні_нмт/довідкові_зін.py довідкові.pdf` (зміст офіційних довідкових НМТ
на трьох сторінках: таблиця квадратів, алгебра й початки аналізу, тригонометрія, геометрія з рисунками TikZ, координати й вектори);
у збирання -- `--довідкові довідкові.pdf` (тоді ПРО_МЕНЕ_І_ДОВІДКОВІ.pdf не потрібен, замість нього «-»). Фінальний PDF каналу --
усе в зіні:

```bash
python3 scripts/пробні_нмт/оформлення_канал.py пробні/канал_1 обкладинка.pdf - Авторський_НМТ_канал_1.pdf \
    --про-мене про_мене.pdf --довідкові довідкові.pdf --дизайн зін
```

Класичне оформлення (без `--дизайн зін`, довідкові -- сторінки 3--5 авторського PDF) -- робоча версія.
«Як справжній НМТ» -- `--дизайн нмт` з обкладинкою «-» (`scripts/пробні_нмт/тема_нмт.py`): титулка в рамці з інструкціями й
блоком «Варіант N», довідкові (сторінки 3--5 авторського PDF або `--довідкові`), завдання з номером на полі й клітинками для
чернетки (сітка розтягується на вільне місце сторінки: `\flushbottom` + `\cleaders`), рисунки в сірому, «Кінець зошита», бланк
відповідей і ключ. Без логотипів і назв УЦОЯО: на титулці -- «авторський пробний тест, не є офіційним матеріалом».

```bash
python3 scripts/пробні_нмт/оформлення_канал.py пробні/канал_1 - "~/Downloads/4 червня автор 2.pdf" Як_справжній_НМТ.pdf --дизайн нмт
```
